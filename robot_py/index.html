Acciones

  • avanzar() — un paso adelante
  • girar_izquierda() — gira sobre su sitio
  • girar_derecha() — gira sobre su sitio
  • romper() — rompe la roca de delante (el acero no)

Sensores (True / False)

  • camino_libre() — no hay nada delante
  • hay_roca() — hay una roca delante
  • hay_pared() — hay un muro delante
  • en_meta() — el robot está en la meta
🐍 Recordatorio de Python 
# for: repetir un número fijo de veces
for i in range(3):
    avanzar()

# while: repetir MIENTRAS algo sea cierto
while not en_meta():
    ...

# if / elif / else: decidir según un sensor
if camino_libre():
    print("libre")
elif hay_roca():
    print("roca")
else:
    print("muro")
