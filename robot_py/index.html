📖 Funciones que puedes usar
  • avanzar() — da un paso adelante
  • girar_izquierda() / girar_derecha() — gira sobre su sitio
  • romper() — rompe la roca que haya delante (el acero no)
  • camino_libre() — True si no hay nada delante
  • hay_roca() · hay_pared() — True según lo que haya delante
  • en_meta() — True si el robot ya está en la meta
# Repetir con for
for i in range(4):
    avanzar()

# Repetir con while hasta una condición
while not en_meta():
    if hay_roca():
        romper()
    avanzar()
